### Scenario: Sanitized HTML Rendering

#### 1. Scope / Trigger

- Trigger: adding or changing any component that renders user, artifact, remote README, skill, or agent-authored content through an HTML sink.
- HTML sinks include `dangerouslySetInnerHTML`, Markdown renderers using `rehype-raw`, and syntax-highlighting fallbacks that return HTML strings.

#### 2. Signatures

- Artifact code preview: `HighlightedCode({ code, language, ... })`
- Skill markdown preview: `SkillMarkdown({ content, className })`
- Sanitizer dependency: `rehype-sanitize`

#### 3. Contracts

- Text entering `dangerouslySetInnerHTML` must be escaped or generated by a trusted sanitizer/highlighter.
- If `rehype-raw` is enabled to support GitHub README HTML, `rehypeSanitize` must run before `rehypeHighlight`.
- Syntax highlighter error fallbacks must return escaped text, not raw code.
- Allowed raw README tags should be explicit in the sanitize schema; event handlers and scriptable URLs must never be allowed.

#### 4. Validation & Error Matrix

- Highlighting succeeds -> render highlighter-produced HTML.
- Highlighting throws -> render `escapeHtml(code)`.
- Markdown includes safe README HTML such as `<details>`, `<summary>`, or protocol-filtered `<img>` -> preserve via schema.
- Markdown includes `<script>` or event handlers such as `onerror` -> strip during sanitization.

#### 5. Good/Base/Bad Cases

- Good: `rehypePlugins={[rehypeRaw, [rehypeSanitize, schema], rehypeHighlight]}`.
- Base: plain markdown renders without raw HTML.
- Bad: `rehypePlugins={[rehypeRaw, rehypeHighlight]}` or `catch { return code; }` before `dangerouslySetInnerHTML`.

#### 6. Tests Required

- Source or component test that artifact highlight fallback escapes HTML.
- Source or component test that raw skill markdown passes through `rehypeSanitize`.
- Regression test must fail if `rehypeRaw` and `rehypeHighlight` are wired without sanitization between them.

#### 7. Wrong vs Correct

Wrong:

```tsx
catch {
  return code;
}
```

Correct:

```tsx
catch {
  return escapeHtml(code);
}
```
