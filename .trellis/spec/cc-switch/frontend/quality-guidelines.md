# Quality Guidelines

> Code quality standards for the cc-switch package.

---

## Status: Not in active use (as of 2026-06-03)

The cc-switch package spec is **scaffolded by `trellis init`** but
**no current code in this repository is filed under cc-switch** and
no active task uses `"package": "cc-switch"` (the only package
labels in the trellis task history are `ccgui` and `vibe-kanban`).

The placeholder files were generated by the bootstrap task and are
preserved so that the spec index stays consistent. The day a task
first lands with `package: cc-switch`, this file gets replaced
with real content grounded in that code.

## Where the real conventions live

- **Frontend conventions** (this repo's actual frontend) live in
  `.trellis/spec/ccgui/frontend/`. That is the spec sub-agents
  should read today.
- **Backend conventions** live in
  `.trellis/spec/vibe-kanban/backend/`.
- Gotchas and stack notes for the actual product are in
  `CLAUDE.md` at the repo root.

## When to fill this file

A new spec file here is required when **all** of the following are
true:

1. A task with `"package": "cc-switch"` exists in
   `.trellis/tasks/` (active or recently archived).
2. There is real code in the repository that the package label
   covers.
3. The conventions in that code area differ from `ccgui` enough
   to warrant a separate spec (different framework, different
   state library, different transport).

Until then, treat this file as a marker, not a contract.
