## Tier 1.5 — Live mock-mode run (DONE) — found + fixed 2 latent bugs

Ran the **real conductor loop** (real MiniMax brain via the catalog `claude` executor) against a **throwaway repo + project** (`/tmp/swarm-val-repo`, isolated from the live repo), `REAL_CLI=false` (mock subagents). This exercised the full live wiring that the integration test's synchronous mocks couldn't.

### Live evidence (all confirmed)
- The brain **chose `dispatch_batch`** with 3 engineer agents in one turn (not serial).
- All 3 nodes tagged with one shared `batch_key` → PR4 swimlane grouping works live.
- `## COST / BUDGET` block injected into the loop (budget 2.0 persisted through the live API).
- Throwaway repo `main` ref+tree **never polluted** across all runs.

### Two real latent bugs surfaced (500+ mocked tests missed both) — fixed in `3815f3e`
1. **dispatch completion race (signal-before-register)**: `dispatch_role` launched the runner *before* the caller registered the task; `signal()` dropped results for unregistered tasks. Mock (instant) completion — or a real fail-fast `executor_failed_to_start` — completes before registration → result lost → `dispatch_batch` hangs to `hard_timeout`, merge never runs, worktrees leak. *Observed live: run 1 hung in `awaiting_subagent` with 3 leaked worktrees.* Fixed: register-before-launch + bounded/TTL registry buffering.
2. **no-op merge misclassified as conflict**: `merge_agent_worktrees` treated every `GitError` as a conflict, so an agent producing no changes became a phantom conflict (empty files/diff) that stopped the batch and leaked its worktree. *Observed live: run 2 returned `merge_status=conflict, conflicts=[{files:[],diff:''}]`.* Fixed: `commits_ahead==0` no-op pre-check + empty-conflict catch fallback; real conflicts unchanged.

### Post-fix re-validation (run 3, both fixes)
- `dispatch_batch` returns `batch_complete`, `merge_status=noop`, `noop_merges=[3]`, `conflicts=None` — no hang, no phantom conflict.
- **0 worktree leaks** (vs 3 pre-fix); `main` clean.

Verdict: the swarm orchestration is correct under a real conductor brain; the two bugs that only a live run could surface are fixed and re-verified.
